## STEP 0｜モードを判定する

$ARGUMENTS またはユーザーのメッセージに「復元」「戻す」「リカバリー」「回復」「recover」のいずれかが含まれている場合は **→ STEP R（リカバリーモード）へ進む**。

それ以外は通常の生成フローへ進む。

---

## STEP R｜リカバリーモード

### R-1｜バックアップ一覧を表示する

```bash
ls -lt "/Users/hiroyuki/Documents/Obsidian Vault/eyecatch/backup/" \
  | grep "\.png$" \
  | awk '{print NR". "$NF}' \
  | head -10
```

以下の形式でユーザーに提示する：

```
💾 利用可能なバックアップ（新しい順）

1. 2026-05-13_14-32-10_eyecatch.png
2. 2026-05-13_11-05-44_eyecatch.png
3. 2026-05-12_09-21-33_eyecatch.png
...

どのバックアップを復元しますか？
番号を入力してください（Enterで最新 = 1を選択）：
```

### R-2｜復元対象を特定する

ユーザーの回答から復元するファイルを決定する。
- 番号が指定された場合 → その番号のファイル
- 未入力・「最新」の場合 → 1番（最新）のファイル

選択したファイルのフルパスを変数として保持する：

```
BACKUP_FILE="/Users/hiroyuki/Documents/Obsidian Vault/eyecatch/backup/（選択ファイル名）"
```

### R-3｜確認ダイアログを表示する

復元前に必ず確認を取る。

```bash
# 選択したバックアップの更新日時を表示
stat -f "%Sm" -t "%Y年%m月%d日 %H:%M:%S" "（BACKUP_FILE）"
```

以下の形式でユーザーに確認する：

```
🔍 復元内容の確認

📂 復元元：（選択バックアップのファイル名）
🕐 作成日時：（上記 stat コマンドの結果）
📁 復元先：/Users/hiroyuki/Documents/Obsidian Vault/eyecatch/（今日の日付）_eyecatch.png

⚠️  復元先に同名ファイルが存在する場合は上書きされます。

この内容で復元しますか？（はい / いいえ）
```

### R-4｜復元を実行する

ユーザーが「はい」「yes」「y」「OK」等を回答した場合のみ実行する。

```bash
# 今日の日付で復元先ファイル名を決定
RESTORE_DEST="/Users/hiroyuki/Documents/Obsidian Vault/eyecatch/$(date +%Y-%m-%d)_eyecatch.png"

# 復元先に既存ファイルがあれば事前バックアップ
if [ -f "$RESTORE_DEST" ]; then
  cp "$RESTORE_DEST" \
     "/Users/hiroyuki/Documents/Obsidian Vault/eyecatch/backup/$(date +%Y-%m-%d_%H-%M-%S)_before-restore_eyecatch.png"
fi

# 復元実行
cp "（BACKUP_FILE）" "$RESTORE_DEST"
```

「いいえ」の場合はキャンセルして終了する。

### R-5｜復元完了報告

```
✅ 復元が完了しました

📂 復元元：（バックアップファイル名）
📁 復元先：（復元先フルパス）

復元前のファイルは backup/ フォルダに退避済みです（上書きがあった場合）。
```

どちらか一方でも欠けている場合は、作業を開始せずに以下のメッセージを返す：

アイキャッチ画像を作成するために、以下の2点をご提供ください。

📷 **背景画像**：画像をチャットに添付するか、ファイルパスをお知らせください
📄 **記事テキスト**：アイキャッチのタイトルを生成する元となる記事本文を貼り付けてください

両方揃った時点で STEP 1 に進む。  
$ARGUMENTS に含まれていればそちらを使用する。

## STEP 1｜タイトルを抽出する

記事テキストを分析し、以下を生成する。

### メインタイトル（1つ）—— 下部バナー用
- 記事の核心的な価値・解決策を凝縮したキャッチコピー
- 読者が「これは自分のための記事だ」と感じる訴求力のある表現
- **2行構成**（意味の切れ目で `\n` を入れる）
- 疑問形・体言止め・数字入りなど目を引く表現を優先
- **強調したいキーワードやフレーズは `《》` で囲む**（金色で描画される）
  - 例：`《「心に寄り添う整理」》で、笑顔あふれる新居を。\n東京都八王子市で《遺品整理・生前整理》をするなら必読。`
  - 目安：1〜2箇所を強調（多すぎると効果が薄れる）

### 上部ボックステキスト（3つ）—— 各ボックス用
各ボックスのテキストを **`白テキスト||金テキスト`** の形式で生成する。

- **白テキスト**：ボックスの見出し・ラベル（10文字以内）
  - 例：「〇〇市民必見！」「料金相場から」「【LINE無料相談】」
- **金テキスト**：白テキストの補足・詳細（15〜20文字）
  - 例：「団地・戸建ての移転・片付けガイド」「優良業者の選び方まで徹底解説」
- `||` でつなぎ、スペースなし
- **折り返し位置を指定したい場合は `\n` を挿入する**（白・金それぞれに使用可）
  - 例：`"料金相場から||優良業者の\n選び方まで徹底解説"`

抽出結果を以下の形式で出力して確認を取る：

```
【メインタイトル（バナー）】
（タイトル）

【ボックス1】（白テキスト）||（金テキスト）
【ボックス2】（白テキスト）||（金テキスト）
【ボックス3】（白テキスト）||（金テキスト）
```

## STEP 3｜画像を生成する

Bash ツールで以下のコマンドを実行する。
引数は **ダブルクォートで囲み**、`||` セパレータをそのまま渡すこと。

```bash
python3 ~/.claude/scripts/generate_eyecatch.py \
  "（背景画像のフルパス）" \
  "（STEP1で確定したメインタイトル）" \
  "（ボックス1のテキスト）" \
  "（ボックス2のテキスト）" \
  "（ボックス3のテキスト）" \
  "/Users/hiroyuki/Documents/Obsidian Vault/eyecatch/（ファイル名）"
```

## STEP 4｜バックアップを作成する

生成した画像を自動でバックアップする。

```bash
cp "/Users/hiroyuki/Documents/Obsidian Vault/eyecatch/（ファイル名）" \
   "/Users/hiroyuki/Documents/Obsidian Vault/eyecatch/backup/$(date +%Y-%m-%d_%H-%M-%S)_eyecatch.png"
```
