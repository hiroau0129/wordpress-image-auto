# 地域特化ランキング記事 完全差別化スキル

## 概要

同一KW（「ネズミ駆除」「遺品整理」等）で複数都市のランキング記事を量産する際、
都市間で内容が完全に被らない「切り口ごと異なる版」を設計・執筆するスキル。

「地名だけ差し替え」は禁止。評価軸・切り口・比較条件を都市ごとにゼロから設計する。

---

## 核心原則：3つの差別化必須要素

都市版を量産するとき、以下の3要素は必ず異なる内容にする。

| 要素 | ✗ 禁止（薄い版） | ✓ 必須（完全差別化版） |
|---|---|---|
| 評価軸（3軸） | 全都市で同じ軸を使い回す | 都市ごとに全軸を変える |
| 切り口・テーマ | 「地名を変えただけ」の記事 | 都市固有の問題を記事の軸にする |
| 比較検証の条件 | 毎回「木造一戸建て」で統一 | 物件タイプを都市の特性に合わせる |

業者ラインナップ・記事フォーマット・アフィリ配置ルールは都市間で共通でよい。

## Step 2：都市特性を分析する（切り口を導く）

以下4観点で都市の「固有性」を洗い出す。

### 産業・経済
- 主要産業は何か（漁業・農業・観光・工業・港湾等）
- 事業者系（旅館・飲食店・工場）の比率
- 地域経済の特徴

### 地理・気候
- 気候（寒冷・温暖・多雪・多雨・沿岸等）
- 特徴的な地形（港湾・山間・平野・川沿い等）
- 季節変動の特性

### 住宅・建築
- 木造比率・築年数の傾向
- 新興住宅地か古い住宅密集地か
- 農村混在か純都市か

### 生活文化
- 観光地かどうか
- 人口構成（高齢化・移住者の多さ等）
- 地域固有の文化・産業

## Step 3：切り口（記事テーマ）を1文で定義する

**テンプレート:**
「[都市名]では[都市固有の特性]があるため、[ジャンル]被害が[他都市と異なる理由・結果]になる」

**実例（ネズミ駆除）:**

| 都市 | 切り口の定義 |
|---|---|
| 高松市 | 瀬戸内の港町・古民家・農業地帯が混在し、ドブネズミとクマネズミ両方の被害が発生する |
| 大分市 | 温泉旅館・飲食店が密集するため、ネズミ被害が保健所問題・廃業リスクに直結する |
| 仙台市 | 東北の冬に断熱材を目当てにした季節性侵入が毎年繰り返されるという固有問題がある |

## Step 4：評価軸3軸を設定する

切り口から逆算して「この都市でその問題を最も解決できる業者を選ぶ軸」を3つ導出する。
**既存版と1軸も被らせない。**

### 軸の候補一覧

| 軸 | 向いている切り口 |
|---|---|
| 対応スピード | 緊急性が高い・当日解決が必要なケース |
| 料金透明性 | 追加料金トラブルが多いジャンル |
| 再発防止力 | 構造的な封鎖が必要なケース |
| 衛生対応力 | 飲食店・旅館・食品工場などの衛生管理ニーズ |
| 断熱材・建材対応力 | 寒冷地・断熱材被害が発生するケース |
| 冬季即日対応力 | 積雪・寒波などの季節リスクがある地域 |
| 施工証明書発行力 | 保健所対応・書類提出が必要な事業者向け |
| 大型施設対応力 | 工場・倉庫・港湾・公共施設が多い都市 |
| 地域密着力 | 地方都市・県外業者が入りにくいエリア |
| 緊急対応力 | 繁忙期対応・24時間体制が求められる業態 |

### 実績（ネズミ駆除3都市）

| 都市 | 軸① | 軸② | 軸③ |
|---|---|---|---|
| 高松市 | 対応スピード | 料金透明性 | 再発防止力 |
| 大分市 | 衛生対応力 | 再発防止力 | 緊急対応力 |
| 仙台市 | 断熱材・建材対応力 | 冬季即日対応力 | 再発防止力 |

## Step 5：差別化する構成要素を事前に決める

### 必ず変えるH2・セクション

| セクション | 変え方の原則 |
|---|---|
| H1・導入文 | 切り口のテーマで書き直す。読者の「悩みの種類」が都市によって違う |
| 放置リスクH2 | 都市の業態から生じる固有リスクを主軸に変える |
| 失敗パターン3選 | 都市固有の失敗（繁忙期・季節・業態）で3パターンを設定 |
| 比較検証H2 | 物件タイプを都市に合わせる（旅館・工場・積雪時の一戸建て等） |
| 地域特性H2 | 都市固有のネズミの種類・侵入経路・季節パターンを書く |
| エリア別H2 | 都市内の地名・地区名・隣接市を全部変える |
| FAQ6問 | 都市固有の質問6問を設定。行政機関名も都市に合わせる |
| まとめの状況別表 | 業者の推薦理由が都市の切り口に沿っていること |

### 変えなくてよいもの
- 1〜3位の業者ラインナップ（オーナー指定・全エリア共通）
- 記事のH2骨格（順序は同じでも中身を変える）
- アフィリリンクの配置ルール（導入後・各社後・まとめ）

## Step 6：執筆後のチェックリスト

### 差別化の確認
- [ ] 切り口（H1・導入）が既存版と全く異なるテーマになっているか
- [ ] 評価軸3軸が既存版と1軸も重複していないか
- [ ] 比較検証の物件条件が都市の特性に合っているか
- [ ] FAQ内の行政機関名は実際にその都市に存在する窓口名か
- [ ] エリア別H2の地名が全てその都市内・近隣の実際の地名か

### 品質の確認
- [ ] 文字数：12,000〜15,000文字（Pythonスクリプトで計測）
- [ ] 文体：「です・ます」調で統一
- [ ] H1タイトル末尾に対象エリアの主要都市名を（〇〇市・△△市・□□市）形式で入れているか
- [ ] 5社構成になっているか（4位・5位はStep 1.5で選定済みのものか）
- [ ] [AFFI:XXX]プレースホルダーが5社分全て揃っているか
- [ ] ファイル名：`[ジャンル]-[都市ローマ字]-ranking.md` で保存

### 文字数計測スクリプト
```python
import re

with open('article.md', 'r', encoding='utf-8') as f:
    text = f.read()

text = re.sub(r'<!--.*?-->', '', text, flags=re.DOTALL)
text = re.sub(r'<[^>]+>', '', text)
text = re.sub(r'https?://\S+', '', text)
text = re.sub(r'[#*_\[\]|`~>]', '', text)
text = re.sub(r'\n+', '\n', text)
chars = len(text.replace('\n', '').replace(' ', '').replace('　', ''))
print(f'本文文字数: {chars}文字')
```

## 4都市目以降の作業順序

3都市を超えて量産する場合は、記事を書く前に全都市分の「切り口マトリクス」を先に設計する。
重複が見えやすく、差別化不足を事前に防げる。

```
① 対象都市リストを確定（例：高松・大分・仙台・福岡・広島・札幌）
      ↓
② 都市ごとに切り口1文を全都市分書き出す
      ↓
③ 評価軸3軸を全都市分表にまとめて重複チェック
      ↓
④ 問題なければ順番に執筆
```

## 注意事項

- 業者の対応エリアは必ず事前確認。「全国対応」を謳っていても実態は限定エリアの場合がある
- FAQ内の市役所・保健所・行政窓口の名称は実在する機関名に合わせる
- 地域特性セクションに書く「ネズミの種類」は地域の生態に合った内容にする
- 口コミの地名・物件タイプは都市の特性に合わせた内容にする
