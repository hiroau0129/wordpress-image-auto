# ランキング記事 構成設計スキル

## 概要

「おすすめN選」形式のSEOランキング記事を設計するスキル。
標準構成に**5つの差別化要素**を組み込み、競合と差別化できる構成を生成する。

---

## Step 1：変数を確認する

ユーザーに以下を確認してから構成を出力する。

| 変数 | 意味 | 例 |
|---|---|---|
| `[メインKW]` | 記事のターゲットキーワード | 遺品整理、着物買取、便利屋 |
| `[エリア]` | 対象地域 | 東京都、大阪市、全国対応 |
| `[N社]` | 紹介する業者数 | 5〜8社 |
| `[CTA種別]` | 最終的な行動喚起の種類 | LINE相談 / 無料見積もり / 電話 |
| `[ペルソナ緊急度]` | 読者の急ぎ具合 | 高（当日・翌日） / 中 / 低 |

---

## Step 2：評価軸を決める（差別化①）

ジャンル特性から評価軸A・B・Cを3つ選ぶ。全社同一軸でレーダーチャートを作成。

| ジャンル特性 | 評価軸の候補 |
|---|---|
| 緊急性が高い（遺品整理・水回り等） | 即日対応力、電話のつながりやすさ |
| プライバシーが絡む | 秘密保持・スタッフの態度、女性スタッフ対応 |
| 費用が不透明になりやすい | 見積もりの明確さ、追加料金なし |
| 物の価値判定が必要（買取系） | 査定精度、高額買取実績 |
| 体力・作業量が大きい | 作業の丁寧さ、後片付けの質 |

---

## Step 3：構成を出力する

```
H1：[メインKW]おすすめ[N]選｜[読者の最大の不安をロングテールで解消]【[年月]最新】

│
├─ 導入
│   ├─ 結論まとめボックス（3行以内・読者が知りたい結論を先出し）
│   ├─ この記事で分かること（箇条書き）
│   └─ CTA①（1位業者 or [CTA種別]）
│
├─ H2：[メインKW]選びで失敗しないために知っておくこと　★差別化②
│   ├─ H3：よくある失敗パターン3選（実例ベース）
│   ├─ H3：悪質業者の見分け方チェックリスト
│   └─ H3：信頼できる業者が持つ3つの条件
│
├─ H2：[メインKW]おすすめ[N]社 比較・紹介
│   └─ [各社フォーマット ×N]
│       ├─ 評価レーダーチャート（[評価軸A/B/C]の3軸）
│       ├─ 基本情報表（対応エリア・方法・許可番号等）
│       ├─ こんな人におすすめ（ペルソナを1行で明記）
│       ├─ メリット・デメリット（各3点）
│       ├─ 実際の口コミ（金額 or 具体的状況入り・2〜3件）
│       └─ CTA（個別）
│
├─ H2：[N]社に同条件で問い合わせた結果を比較　★差別化③
│   ├─ H3：検証条件（依頼内容・状況を統一して明記）
│   ├─ H3：各社の回答・見積もり結果一覧表
│   └─ H3：対応スピード・丁寧さの比較コメント
│
├─ H2：ランキング（アンケートN人調査ベース）
│   ├─ 評価軸：[評価軸A]・[評価軸B]・[評価軸C]
│   ├─ 1位〜[N]位の順位表（スコア数値入り）
│   └─ 総評コメント（1〜2行）
│
├─ H2：あなたの状況別・おすすめ業者の選び方　★差別化④
│   ├─ H3：【急いでいる人向け】対応スピード重視
│   ├─ H3：【不安が強い人向け】丁寧さ・説明重視
│   ├─ H3：【コスト重視の人向け】価格と品質のバランス
│   └─ H3：【特殊な状況の人向け】対応力・柔軟性重視
│
├─ H2：[メインKW]の相場・費用感
│   ├─ 相場一覧表（条件別）
│   ├─ 料金が変わる要因（箇条書き）
│   └─ 見積もりの取り方・注意点
│
├─ H2：[メインKW]業者の利用の流れ
│   ├─ STEP1〜4の図解
│   └─ 各ステップの注意点
│
├─ H2：高く売る・お得に利用するためのポイント
│
├─ H2：[エリア別]対応業者・アクセス情報　★差別化⑤
│   ├─ H3：[市区町村 or 主要駅]ごとの対応業者リスト
│   └─ H3：出張料・エリア外対応の条件
│
├─ H2：よくある質問（Q&A）
│   └─ 読者の不安TOP5を想定問答形式で解消
│
└─ H2：まとめ・最終おすすめ
    ├─ 状況別の最終結論（2〜3パターン）
    └─ CTA②（[CTA種別]）
```

---

## 5つの差別化要素（概要）

| # | 要素 | 効果 |
|---|---|---|
| ① | ジャンル固有の評価軸（3軸） | 競合と異なるランキング根拠を作れる |
| ② | 失敗回避・悪質業者チェック | 読者の警戒心と信頼を同時に取れる |
| ③ | 同条件での1次比較検証 | 検索1位でしか作れない独自コンテンツになる |
| ④ | 状況別ペルソナ分岐 | CVRの改善と検索意図カバーが同時に実現 |
| ⑤ | 市区町村・駅名レベルの地域粒度 | ロングテールKW（「〇〇市 ××」）を複数獲得 |

## よくある失敗パターン（差別化②の参考）

ジャンルに合わせて以下から選んで具体化する：

- **追加料金トラブル**：見積もり後に「処分費」「人件費」が加算された
- **対応の遅さ**：問い合わせから数日音沙汰なし
- **査定額の極端な低さ**：相場より大幅に低い金額を提示された
- **個人情報の取り扱い**：作業後に近所に知られた
- **作業品質のトラブル**：雑に扱われた・傷をつけられた

---

## 備考

- **記事全体の本文文字数：12,000文字以上・15,000文字以内を厳守する**（装飾記号・HTMLタグを除いた本文テキストで計測）
- 構成出力後は `article-design` スキルと併用して最終調整可
- CTA配置は「導入直後・各社紹介後・まとめ」の最低3箇所
