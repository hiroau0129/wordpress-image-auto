# Phase 2: リサーチエージェント

**目的**: 記事作成に必要な情報を収集し、記事構成の骨子を生成する

**所要時間**: 約20分

> **注記**: X（Twitter）・YouTubeは便利屋・遺品整理ジャンルにおいて有効な一次情報が少ないため、本フローでは対象外とする。代わりにQ&Aサイト・レビュー・パートナーヒアリングを一次情報源とする。

---

## 実行フロー

### Step 1: SERP分析

対象KWでGoogle検索し、上位5記事の構成を取得・整理する。

**取得する情報**:

```
- 上位5記事のURL・ドメイン・DR（Ahrefs）
- 各記事のH2・H3見出し一覧
- 文字数の概算
```

**整理する観点**:

| 観点 | 内容 |
|:---|:---|
| 必須トピック | 上位5記事中3記事以上で共通して書かれている見出し |
| 差別化余地 | 1〜2記事しか触れていないトピック |
| 空白地帯 | どの記事も書いていないが検索意図に合うトピック |

**出力**: 見出しマトリクス（KW × 記事ごとの有無）

---

### Step 2: Q&Aサイト調査

ユーザーのリアルな悩み・疑問を収集する。

**調査先**:

1. **Yahoo!知恵袋**
   - 検索クエリ例: `「遺品整理」OR「生前整理」OR「仏具 買取」`
   - 取得件数: 10〜20件
   - 抽出ポイント: 質問文・ベストアンサー・回答数が多いもの優先

2. **教えてgoo**
   - 同様のクエリで検索
   - 取得件数: 10件

**整理する観点**:

- 頻出する悩みのカテゴリ（費用・手順・業者選び・トラブルなど）
- 感情ワード（「困っている」「不安」「騙された」など）
- 記事内でそのまま使えるFAQ候補

**出力**: 悩みカテゴリ別リスト（各カテゴリ3〜5件）

---

### Step 3: Googleマップ レビュー収集

実際の利用者の声から差別化ポイントを抽出する。

**調査先**:

1. **Googleマップ（競合業者の口コミ）**
   - 対象エリア: 神奈川県全域（愛川町・相模原市・厚木市・横浜市など）および東京都西部（八王子市・町田市・多摩市など）
   - 評価4以上のレビューから「満足した理由」を抽出
   - 評価2以下のレビューから「不満・不安だったこと」を抽出
   - ネガティブレビューを優先収集（記事内の「失敗しないための注意点」に活用）

**整理する観点**:

| 種別 | 活用場所 |
|:---|:---|
| ポジティブレビュー | 選ばれる理由・安心感の訴求 |
| ネガティブレビュー | 注意点・よくあるトラブル・比較軸 |
| 繰り返し出てくるワード | 記事内の自然な言葉遣いに反映 |

**出力**: ポジティブ/ネガティブ別レビューリスト（各10件程度）

---

### Step 4: パートナーヒアリング項目の生成

対象KWに応じて、JVパートナー（長谷川さん・山本さん）への確認事項リストを自動生成する。

**ヒアリング項目テンプレート**:

```
【基本情報】
□ このサービスで一番多い相談内容TOP3は何ですか？
□ 断るケース・対応できないケースはありますか？
□ 作業にかかる標準的な時間・費用感を教えてください

【地域特有の事情】
□ 愛川町・周辺エリアで特有の事情や傾向はありますか？
□ 季節によって依頼が増える時期はありますか？

【ユーザー心理】
□ お客さんが作業前に一番不安に思っていることは何ですか？
□ 作業後にお客さんが一番驚くこと・喜ぶことは何ですか？
□ リピート・紹介につながるケースの共通点はありますか？

【差別化ポイント】
□ 他の業者と比べて自社が優れている点を教えてください
□ 実際の作業事例で紹介できるものはありますか？（写真があれば尚可）
```

> KWが「仏具買取」「着物買取」などフロントKWの場合は、該当カテゴリに絞った質問に自動で絞り込むこと。

**出力**: KW別カスタマイズ済みヒアリングシート（パートナーにそのまま送れる形式）

---

### Step 5: 記事構成骨子の生成

Step 1〜4の情報を統合し、記事の見出し構成案を作成する。

**構成の原則**:

```
H1: KW + ユーザーの悩みを解決する表現
　H2: この記事でわかること（導入）
　H2: [必須トピック①]　← Step1の共通見出しから
　H2: [必須トピック②]
　H2: [差別化トピック]　← Step1の空白地帯 or Step2の悩みから
　H2: よくある質問　　　← Step2のFAQ候補から
　H2: まとめ・LINE相談への導線
```

**チェック観点**:

- [ ] ユーザーの悩み（Step2）が見出しに反映されているか
- [ ] 競合にない独自トピック（Step1空白地帯）が1つ以上あるか
- [ ] 記事末尾にLINE相談への自然な導線が設計されているか（「まず気軽に相談」という文脈で）
- [ ] パートナーヒアリング（Step4）で得られる情報を入れる箇所があるか

**出力**: H1〜H3レベルの見出し構成案（Markdown形式）
